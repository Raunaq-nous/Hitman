# Walkthrough

How to run: `node harness/init.mjs`, then `npm run dev` (http://localhost:3000). No keys or paid data needed (`LIVE_CALLS=false`; without `GEMINI_API_KEY` the language layer uses templates). The full gate is `node harness/verify.mjs`; the clean-clone gate is `node harness/verify.mjs --clean`.

Each screen below links its screenshot evidence (1280 px and 390 px, light and dark, unless noted). Performance: [perf-2026-10-23.json](evidence/F-U-07/perf-2026-10-23.json) (LCP 0.62–0.68 s on slow-4G mobile).

## Journeys
- Call → review → next read on a 390 px phone in about 4 seconds (`tests/e2e/journey.spec.ts`), with analytics events checked in the database.
- Ten graded calls → Dossier Reveal → opt-in share card (`tests/e2e/reveal.spec.ts`).
- Crew → timing tower with two members (`tests/e2e/tower.spec.ts`).
